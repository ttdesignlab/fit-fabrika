# Fit Fabrika – sajt

## PRE OBJAVLJIVANJA (obavezno)
U svim fajlovima zamenite tekst `https://ADRESA-SAJTA` pravom adresom sajta (bez kose crte na kraju), npr. `https://www.fitfabrika.rs`.
Fajlovi: index.html, prostor.html, edukacija.html, online-treninzi.html, politika-privatnosti.html, robots.txt, sitemap.xml.
(VS Code: Edit → Replace in Files.)

## Postavljanje na GitHub Pages
1. Raspakujte ZIP.
2. Repozitorijum → Add file → Upload files → prevucite SVE iz ovog foldera (i folder img).
3. Settings → Pages → Branch: main / root → Save.

Stranice su čist HTML (bez React-a). Interakcije (tema, meni, forma, galerija) su u site.js.
